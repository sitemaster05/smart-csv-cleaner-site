Questions

Before you run the first batch.

Does the app upload my CSV files?

No. Version 1.0.0 has no networking code. Files are read and written on the local Windows computer.

Does it overwrite the original?

No. Outputs use a _cleaned.csv suffix. If a name already exists, the app adds a number instead of replacing it.

Can I use it for paid client work?

Yes. The Personal license permits commercial data-processing work by the named buyer. A Business license covers multiple users.

Why might Windows show a warning?

The first release is independently distributed and is not code-signed. Verify the official download and its published SHA-256 before running it.

Who processes the payment?
