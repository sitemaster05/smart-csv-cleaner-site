# Smart CSV Cleaner Pro — website

Static product page for [Smart CSV Cleaner Pro](https://sitemaster05.github.io/smart-csv-cleaner-site/),
a local-first Windows app that batch-cleans messy CSV files and produces before/after reports.

- `index.html` — product page with an in-browser demo, pricing and FAQ
- `terms.html` — license summary and refund policy
- `privacy.html` — privacy policy

The free open-source command-line version lives at
[sitemaster05/smart-csv-cleaner](https://github.com/sitemaster05/smart-csv-cleaner).

No build step, cookies, analytics or trackers. Checkout links are configured in `CHECKOUT_URLS` in `app.js`.
